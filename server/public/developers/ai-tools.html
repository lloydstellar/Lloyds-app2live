AI tools

An AI coding tool can build a Send to Live feature from these pages. The helpers below put the same few things in front of it: install la2l, pair with a code field, render WAV, give every sound kind, role and bpm, and test with the test receiver.

The skill

la2l-send-to-ableton is an Agent Skill: the steps, the pitfalls, the API, and examples that are tested against the SDK.

Agents leave a skill unused more often than you would think. Name it in your prompt: "Add a Send to Live button with LA2L. Use the la2l-send-to-ableton skill."

A docs index in AGENTS.md

npm install la2l
npx la2l agents-md

This writes an index of the docs in node_modules/la2l/docs into AGENTS.md, and into CLAUDE.md when the project has one, with the rules that matter most. Agents read AGENTS.md at every task, so they find the docs of the version you installed instead of guessing. A new run, after an update of la2l, replaces the index.

Lovable, Bolt and other builders without a terminal

Paste the paste text into the knowledge of the project: in Lovable under Knowledge, in Bolt in the project's knowledge or system prompt. It works on its own: installing, the button, rendering a loop, the pitfalls, and where the docs are. Copy it from its Markdown version to keep the formatting.

llms.txt

llms.txt lists these pages for language models, and llms-full.txt holds them all in one file. Every page is there as Markdown too: add .md to its address (the start page is index.md).

Check what the tool built

Open the test receiver in a second tab, pair the app with the code it shows, and send. The report says per sound what Live would do. A loop must show up as a loop at the tempo of the app, such as "Loop, warped in Beats mode at 120 BPM, 4 beats". When it says "One-shot", the app forgot kind: 'loop'. An agent that can run commands can test its own work: npx la2l test-receiver --local (Testing).
